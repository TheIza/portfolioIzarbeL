# Portfolio IzarbeL

Portfolio personal desarrollado para mostrar mi perfil, formación, proyectos y habilidades como estudiante de **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

El proyecto está creado con **HTML, CSS y JavaScript**, y cuenta con diferentes versiones del portfolio según el idioma.

## Demo

Puedes ver el portfolio publicado en GitHub Pages:

**https://theiza.github.io/portfolioIzarbeL/**

## Idiomas

El portfolio está disponible en:

- Español
- Catalán
- Inglés

Cada idioma tiene su propio archivo HTML:

```text
index.html
index_ca.html
index_en.html
```

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

## Características

- Portfolio personal responsive.
- Diseño personalizado.
- Soporte para tres idiomas.
- Sección de presentación personal.
- Información sobre formación y habilidades.
- Presentación de proyectos realizados.
- Uso de JavaScript para elementos interactivos.
- Recursos gráficos organizados en una carpeta propia.
- Publicación mediante GitHub Pages.

## Objetivo

El objetivo del proyecto es crear un espacio personal donde poder mostrar mi evolución como desarrolladora, mis conocimientos y los diferentes proyectos realizados durante mi formación.

El portfolio también sirve como carta de presentación para futuros proyectos, prácticas y oportunidades laborales.

## Estado del proyecto

**En desarrollo**

El portfolio se irá actualizando a medida que avance mi formación y vaya incorporando nuevos proyectos, tecnologías y conocimientos.
